# 📚 Nammapustaka - Smart Library App

            Project Title
Nammapustaka Smart Library Management System

---

## 📖 Description
This Android application helps students manage and access library books digitally. It provides an easy interface to view books and manage library-related data.

---

## 🎯 Problem Statement
Traditional library systems are manual and time-consuming. Students face difficulty in tracking books and availability.

---

## 💡 Solution
This app provides a digital platform where users can:
- View available books
- Access book details
- Improve library management efficiency

---

## 🛠️ Technologies Used
- Kotlin
- Android Studio
- XML
- Firebase / SQLite 
- Gradle
